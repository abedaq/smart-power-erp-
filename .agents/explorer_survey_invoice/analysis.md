# تقرير الاستكشاف الشامل: نموذج الفاتورة المعتمد ومطابقة التصميم وتوحيد مخرجات الطباعة والواتساب
**تاريخ الاستكشاف**: 2026-09-02  
**المستكشف**: Explorer 2 (Invoice Template Survey)  
**حالة الفحص**: مكتمل وشامل

## 1. ملخص تنفيذي (Executive Summary)
يهدف هذا الاستكشاف إلى دراسة وتحليل دورة حياة الفاتورة بالكامل عبر نظام Smart Power ERP (الواجهة الأمامية React، الواجهة الخلفية Node.js/EJS/Puppeteer، وتطبيق الهاتف Flutter)، وتحديد جميع المكونات المسؤولة عن عرض الفواتير، معاينتها، طباعتها (A4 / حراري / كشف تجميعي)، تحويلها إلى صور/PDF، وقوالب رسائل الواتساب (`WhatsApp Text & Image Templates`).

تمت مطابقة الوضع الحالي بدقة مع النموذج المعتمد في الصورة الرسمية `photo_5769554780358381104_y.jpg`، ورصد جميع الفروقات، ومواضع الازدواجية، وخطة التوحيد الشاملة لضمان صدور فواتير متطابقة 100% في جميع الشاشات والمخرجات.

## 2. التحليل التفصيلي للصورة المرجعية الرسمية (`photo_5769554780358381104_y.jpg`)

تُمثل الصورة المرجعية نموذج فاتورة استهلاك طاقة كهربائية رسمية بنظام **الكعب المزدوج (Dual-Stub / Split Layout)**، والمقسومة رأسياً إلى قسمين محاطين بإطار خارجي أسود:

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                       الإطار الخارجي الأسود                                      │
├───────────────────────────────────────────────────────┬──────────────────────────────────────────┤
│           القسم الأيسر: فاتورة المشترك (60%)           │      القسم الأيمن: كعب المحطة (40%)      │
├───────────────────────────────────────────────────────┼──────────────────────────────────────────┤
│ 1. الترويسة: شعار يسار + اسم المحطة + الهواتف + الحساب│ 1. الترويسة: شعار يسار + اسم المحطة+هواتف│
│ 2. بيانات المشترك: الاسم، العنوان، الاشتراك، العداد...│ 2. بيانات المشترك: الاسم، العنوان، العداد│
│ 3. عنوان الدورة باللون الأحمر (فاتورة استهلاك كهرباء) │ 3. عنوان الدورة باللون الأحمر            │
│ 4. جدول 7 أعمدة:                                      │ 4. جدول 5 أعمدة:                         │
│    [ق.سابقة | ق.حالية | الفارق | اشتراك | قيمة | متأخرات | إجمالي]│    [ق.سابقة | ق.حالية | الفارق | متأخرات | إجمالي] │
│ 5. شروط وتعليمات المحطة (5 بنود باللون الأحمر):       │ 5. توقيعات: المحصل (يمين) - الحسابات(يسار│
│    - السداد يوم الاستلام أو التالي...                 │                                          │
│    - فصل التيار عند التأخر...                         │                                          │
│    - غرامة التوصيل للغير 200,000 ريال...              │                                          │
│    - عدم تحمل مديونية موظف بدون سند رسمي...           │                                          │
│    - سعر الكيلو 1400 ريال والمتغير مع الديزل...       │                                          │
│ 6. توقيعات: المحصل (يمين) - الحسابات (يسار)           │                                          │
├───────────────────────────────────────────────────────┴──────────────────────────────────────────┤
│ أسفل اليسار: التاريخ: 2026/07/17 (أرقام إنجليزية حصراً)                                         │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### تفاصيل البنية والعناصر:
1. **القسم الأيسر (فاتورة المشترك - Main Customer Bill)**:
   - **الترويسة (Header)**:
     - شعار المحطة الدائري (Station Logo) يقع في أقصى اليسار.
     - اسم المحطة بالوسط بخط عريض: `محطة الضياء لتوليد الطاقة الكهربائية`.
     - أرقام هواتف المحطة باللون الأزرق: `783270260_736955883`.
     - عبارة الإيداع البنكي: `يمكنك الإيداع على الحساب 3052001225`.
   - **بيانات المشترك والفاتورة (Customer Info Grid)**:
     - العمود الأيمن: `اسم المشترك : [الاسم]`، `العنوان : [العنوان]`، `رقم المشترك : [الرقم]`، `رقم العداد : [العداد]`.
     - العمود الأيسر: `رقم الفاتورة: [الرقم]`، `رقم خط السير: [الخط]`.
     - عنوان الدورة في المنتصف باللون الأحمر: `فاتورة استهلاك كهرباء [الشهر والدورة]`.
   - **جدول الاستهلاك والمالية (7 أعمدة RTL)**:
     1. `قــــراءة العداد` (رأس مدمج لعمودين: `ق. السابقة` و `ق. الحالية`).
     2. `الفارق` (كمية الاستهلاك = الحالية - السابقة).
     3. `اشتراك` (رسوم الخدمة الثابتة - Fixed Service Fee).
     4. `القيمة` (قيمة الاستهلاك = الفارق × التعرفة).
     5. `متأخرات` (المديونيات السابقة).
     6. `الاجمالي` (إجمالي المستحق = القيمة + الاشتراك + المتأخرات).
   - **صندوق التعليمات والضوابط الرسمية (5 بنود باللون الأحمر)**:
     1. يتم سداد الفاتورة يوم استلامها او اليوم التالي فقط.
     2. في حالة تأخر السداد سيتم فصل التيار دون إشعار مسبق ولن يعاد الا بغرامة.
     3. في حال قيام المشترك بتوصيل التيار لشخص آخر سيتم تغريم المشترك مبلغ وقدره 200000 مائتان الف ريال
     4. يتحمل المشترك مديونية أي موظف إن لم يكن هناك سند رسمي مختوم بختم المحطة.
     5. سعر الكيلوواط/ ساعة 1400 ريال ويرتفع سعر الكيلو بنسبة وتناسب بارتفاع الديزل.
   - **التوقيعات (Signatures)**:
     - `المحصل` على اليمين مع خط تنقيط `....................`
     - `الحسابات` على اليسار مع خط تنقيط `....................`
   - **التاريخ**: أسفل اليسار بصيغة إنجليزية `التاريخ: 2026/07/17`.

2. **القسم الأيمن (كعب المحطة / إشعار التحصيل - Collector Stub / Counterfoil)**:
   - الترويسة: الشعار يساراً، اسم المحطة وأرقام الهواتف.
   - بيانات المشترك: الاسم، العنوان، رقم المشترك، رقم العداد، وعنوان الدورة بالأحمر.
   - جدول الحسابات (5 أعمدة RTL): `ق. السابقة`، `ق. الحالية`، `الفارق`، `متأخرات وغرامات`، `الاجمالي`.
   - التوقيعات: `المحصل` (يمين)، `الحسابات` (يسار).

## 4. الفروقات والعيوب المرصودة مقارنة بالصورة الرسمية (Gap Analysis)

1. **انعكاس ترتيب القسمين (Stub Inversion)**:
   - **الواقع في الصورة الرسمية**: الفاتورة الرئيسية (7 أعمدة + الشروط) على **اليسار**، وكعب المحطة (5 أعمدة) على **اليمين**.
   - **الوضع الحالي في الكود**: في كل من `InvoicePreviewModal.tsx` و `CyclePrintView.tsx` و `invoice.ejs`، عند تطبيق `dir="rtl"`، يظهر العنصر الأول في اليمين، مما جعل الفاتورة الرئيسية تظهر على اليمين وكعب المحطة على اليسار (معكوس).

2. **مخالفة قاعدة الأرقام الإنجليزية في قالب السيرفر**:
   - في `backend/src/templates/invoice.ejs`، سطر التاريخ يولد التاريخ بصيغة `ar-YE` أو `toLocaleDateString` مما ينتج أرقاماً مشرقية (مثل `٢٠٢٦/٩/١`)، كما لوحظ في العينة المولدة `live_db_invoice_rendered.png`. يجب فرض الأرقام الإنجليزية (`en-US` / `en-GB`).

3. **ازدواجية نموذج المعاينة في الواجهة الأمامية**:
   - يوجد نموذجان للمعاينة: `InvoicePreviewModal.tsx` (يطابق الكعب المزدوج) و `InvoiceModal.tsx` (نموذج كرتي مفرد بسيط داخل `ExcelGrid`). يجب توحيد الواجهات بحيث يفتح جدول Excel النموذج المعتمد ذو الكعب المزدوج لتفادي أي التباس لدى الكاشير والمحصلين.

4. **تثبيت موضع الشعار والهواتف**:
   - في الصورة المعتمدة، يقع الشعار في الزاوية اليسرى من ترويسة كلا القسمين، بينما تقع النصوص في المنتصف. في بعض القوالب تم وضع الشعار يميناً بسبب انعكاس اتجاه النص.
