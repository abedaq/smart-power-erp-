# flutter-core-architecture Skill Reference
Source: C:\Users\hey12\.gemini\config\skills\flutter-core-architecture\SKILL.md

The 6 Core Layers:
1. UI / UX (Loading, Error, Empty, Skeleton, Refresh, Dialog, Snackbar, Accessibility)
2. Navigation (Router, Guards, Deep Links, Auth Redirect)
3. Data (API, Cache, Database, Serialization, Pagination, Offline Queue & Outbox, Sync)
4. Performance (Debounce, Throttle, Cancellation, Lazy Loading, Image Cache, Rebuild Optimization, Lifecycle)
5. Security (Authentication, Authorization, Secure Storage, Permissions, HTTPS, No Hardcoded Secrets)
6. Operations (Logging, Crash Reporting, Analytics, Remote Config, App Updates, Testing, Feature Flags)

Key Rule: Event-Driven execution (No continuous polling timers).
